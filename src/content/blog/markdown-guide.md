写博客时最常用的几种语法。

## 标题

```
## 二级标题
### 三级标题
```

## 强调与代码

**加粗** 用 `**文字**`，*斜体* 用 `*文字*`，行内代码用反引号。

代码块用三个反引号包裹，可以标注语言：

```js
const greeting = 'Hello';
console.log(greeting);
```

## 列表与链接

- 无序列表项
- 另一项

1. 有序列表第一项
2. 第二项

链接写法：[Astro 文档](https://docs.astro.build)

## 引用

> 引用文字前加 `>`。

 Markdown 写起来很轻，不用记住太多规则。
